# Launch checklist

Copy this file into an issue or a pull request to track progress. GitHub shows the boxes as tickable.

## 1. Baseline

- [ ] Performance split by campaign, keyword, audience, lead source and segment
- [ ] CPL, qualification, account-opening and first-trade rates captured
- [ ] Cost per activated customer calculated for every campaign

## 2. Signals

- [ ] Click ID stored on every lead record
- [ ] Qualified, account-opened and first-trade events sent back to the ad platforms
- [ ] Consent, hashing and compliance reviewed

## 3. Bidding

- [ ] Target CPA live on a reliable event
- [ ] Targets tightened in steps, not in one jump
- [ ] Conversion values agreed with Finance before testing target ROAS

## 4. Reallocation

- [ ] Budget moved towards campaigns with the lowest cost per activated customer
- [ ] DIY share target set, with a plan that does not depend on RM capacity
- [ ] Results reviewed on activated customers, not enquiries
