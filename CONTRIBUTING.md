# Contributing

Suggestions are welcome, whether they are corrections, better benchmarks or new examples.

## Good changes

- A corrected or updated benchmark, with a link to the source and the date you retrieved it.
- A clearer explanation of a step, or a gap in the checklist.
- A fix to a calculator, with an example input that shows the problem.

## How to propose a change

1. Open an issue describing what you would change and why, or start a pull request directly for small fixes.
2. Keep changes small and focused.
3. If you change a number in `index.html`, change the matching row in `docs/benchmarks.md` or `docs/playbook.md` in the same pull request.

## Rules for figures

- Every benchmark needs a source link and a retrieval date.
- Mark each figure as reported, derived or secondary, as in `docs/benchmarks.md`.
- Do not add figures that come from confidential or internal data.
- Keep calculator example inputs labelled as illustrative.
